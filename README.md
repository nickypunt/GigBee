# GigBee 🐝

A marketplace that connects college students with local businesses and individuals for one-time gigs like event help, tutoring, babysitting, and social media work.

🔗 **Site:** [getgigbee.com](https://getgigbee.com)

## Features
- Students browse local gigs and apply in a few clicks
- Employers post gigs, review applicants, and update application status
- Google sign-in with school-email verification for students
- Email notifications and account authentication

## Tech Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, shadcn/ui
- **Backend & Database:** Supabase (Postgres, Auth)
- **Email:** Resend
- **Hosting:** Vercel
- **Development:** Built with Cursor AI
